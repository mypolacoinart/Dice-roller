# Dice Roller

A simple command-line dice roller that uses standard dice notation, built for tabletop RPG sessions.

## Features

- No external dependencies, only the Python standard library (`random` and `re`)
- Standard dice notation: `2d6`, `d20`, `4d8`
- Bonuses and penalties: `1d12+3`, `2d6-2` (currently working on it)
- Shows each individual die, the modifier, and the total
- Keeps prompting for new rolls until you quit
- Saving throw: Handles invalid input without crashing

## About the project

My friends and I love playing role-playing games, and that's what motivated this project. I built it during my first year of college as a way to apply what I had recently learned in Python.
