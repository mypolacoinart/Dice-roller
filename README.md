# Dice-roller
A simple command-line dice roller that uses standard dice notation (e.g. `2d6`).

### A little about the project

The motivation behind developing this small project came from the fact that my friends and I really playing role-playing games. During my first year of college, I decided to build this project in Python as a way to apply the knowledge I had recently acquired. Now, with a deeper understanding of the subject and equipped with concepts related to algorithms and data structures, I saw an opportunity to revisit the project and conduct a more in-depth analysis of its runtime complexity.

## Requirements

- Python 3.6+
